# School Club Website

## Setup Requirements

- Git
- Node.js (v22 or higher)

## Setup Instructions

1. Clone the repository: `git clone git@github.com:asciislvt/school-club.git`
2. Run `npm install` to install dependencies.
3. Run `npm run dev` to start the development server.
4. Open your browser and navigate to `http://localhost:5173` to view the page.
